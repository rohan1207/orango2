1. What changed — in one page

The audit found the old WordPress / Elementor site was not selling the product: empty hero, dead CTAs, thin B2B pages, missing indexation assets, and copy that sometimes sounded like bottled juice. The new site keeps the orange / cream visual system and homepage motion you approved, and rebuilds information architecture, content, CTAs, and SEO so a mall or hospital manager can understand the offer and request a site survey in seconds.

3. Audit points closed

UI & conversion

  • Primary CTA language standardised — no lone “Get In Touch” / dead # links
  • Header WhatsApp + “Book a site survey”; mobile sticky bar with both
  • ₹120 / 45s / UPI / 4°C present as live content (not only PNG price art)
  • For Locations venue tabs + “What we need from you” (≈12 sq. ft., power, loading)
  • Partners: three sober columns + five-step timeline — no café stock pitch
  • Machine page: full spec table facilities can screenshot into WhatsApp
  • Support form aligned to refund policy (UTR + Machine ID)
  • 404 recovery paths to Home / Find / Site survey
  • Thank-you page for post-enquiry tracking

Trust & legal

  • Footer names INNOVERTEX LLP, full NAP, hello@ / partnerships@ / support@
  • GSTIN & FSSAI placeholders ready for client numbers
  • Public LinkedIn company URL (not viewAsMember private link)
  • Naming standardised to OranGo in titles, H1s, and schema
  • Health copy framed for sealed-cup vending (not “every bottle / cold-press”)
  • Hospital disclaimer on machine hygiene section

Homepage constraint (client brief)

  • Homepage visual system and animations were not redesigned
  • Only CTAs, destinations, and SEO/metadata copy were updated on home
  • New B2B sections live on dedicated pages so the hero composition stays intact

5. Content model published

  • Product: Valencia oranges · ~45 seconds · 4°C · UPI · ozone · sealed cup · from ₹120
  • Commercial model (words): venue provides bay + power; OranGo installs, restocks, cleans
  • Audience: facility / mall / hospital managers first; consumers via Find OranGo
  • Differentiation vs name collision: titles and schema say OranGo — fresh orange juice vending machines in India
